为什么地球上的河流几乎总是弯弯曲曲的？

从高空俯瞰平原上的大河，几乎见不到笔直的河道，哪怕最初人工开凿的直线运河，日久也会扭成优雅的“S”形曲流。这并非单纯出于地形石块的阻挡，而是流体在旋转、惯性与摩擦之间自发演化的物理结果。

只要河道存在极其微小的初始弯曲，水流转弯时，表层流速较快的水体在离心力作用下会被甩向凹岸（外侧），使凹岸水位略微高于凸岸。而在贴近河床的底层，水体因摩擦阻力大幅减速，所受离心力弱于由水位差产生的向内压力梯度。于是，表层水向外侧涌去、底层水贴着河底向内侧回流，在河道横截面上构成一股螺旋前进的“次级环流”。

这股环流不断冲刷淘蚀高速流动的凹岸，同时将泥沙顺着底层水流搬运并沉积在流速较缓的凸岸，让微小的弯道在正反馈中越滚越大。有趣的是，1926 年爱因斯坦曾在一篇短文中用完全相同的机制解释了“茶叶悖论”：搅动茶杯时，茶叶不会因离心力贴满杯壁，反而被杯底向内聚拢的次级环流推向杯底中央——一只茶杯与亚马逊河，服从着同一套流体力学定律。

把针弯成面条：不用积分也能算出布丰投针

1777 年，法国博物学家布丰提出了一个经典几何概率问题：在画满间距为 $d$ 的平行线的平面上，随机抛下一根长为 $\ell$（$\ell \le d$）的直针，它与平行线相交的概率是多少？标准解法需要设出针心距离与倾角，再对正弦函数求定积分。然而在 1860 年，数学家约瑟夫-埃米尔·巴比耶（Joseph-Émile Barbier）给出了一个几乎像“作弊”一样巧妙的证明：不妨把刚性的针想象成一根可以随意弯曲的“面条”。

设想将任意一条总长为 $L$ 的平面曲线随机均匀地抛向这组平行线，记它与平行线的总交点个数为随机变量 $N$。无论曲线如何弯折，我们都可将其近似拆分为 $m$ 段极短的直微元，每段长度为 $\Delta l_i$，满足 $\sum_{i=1}^m \Delta l_i = L$。记第 $i$ 段微元与平行线相交的次数为 $X_i$，则 $N = \sum_{i=1}^m X_i$。这里最关键的一步是**期望的线性性质**：即便各段微元被刚性锁定在同一条曲线上、彼此高度相关，总期望依然严格等于各微元期望之和，即 $\mathbb{E}[N] = \sum_{i=1}^m \mathbb{E}[X_i]$。由于整体曲线的落点与朝向完全均匀随机，每一小段微元边缘分布相同，其期望交点数必定正比于自身长度 $\Delta l_i$。因此，存在一个仅与线距 $d$ 有关的常数 $c$，使得对任意形状、总长为 $L$ 的曲线都有 $$\mathbb{E}[N] = c L$$

接下来只需挑一条最“听话”的曲线来定出常数 $c$。取一个直径恰为 $d$ 的圆，它的周长是 $L = \pi d$。妙处在于，只要把这个圆随机扔在间距为 $d$ 的平行线上，无论圆心落在何处，除概率为零的相切情形外，它**必然**与某一条平行线恰好相交两次！也就是说，$\mathbb{E}[N_{\text{圆}}] = 2$。代入上式立刻得到 $c \cdot \pi d = 2$，即 $c = \frac{2}{\pi d}$。回到最初长为 $\ell \le d$ 的直针，它至多只能与一条线相交（$N \in \{0, 1\}$），此时相交概率恰好等于期望交点数：$P(N=1) = \mathbb{E}[N] = \frac{2\ell}{\pi d}$。无需一笔积分，仅凭期望线性性与几何对称性联手，便从面条的曲折中精准抽出了 $\pi$。
